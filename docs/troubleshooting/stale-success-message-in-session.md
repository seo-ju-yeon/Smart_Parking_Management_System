# 관리자 등록 성공 메시지가 다음 화면에 남은 문제

## 문제 상황

관리자를 정상적으로 등록한 뒤 다시 관리자 추가 화면으로 이동하면 이전 등록의 성공 메시지가 다시 표시되었다. 화면을 새로고침해야 메시지가 사라졌다.

## 원인 확인

관리자 등록 성공 메시지를 세션에 저장한 뒤 대시보드로 이동했지만, 대시보드에서는 해당 메시지를 읽거나 삭제하지 않았다.

이후 관리자 추가 화면이 세션의 메시지를 뒤늦게 읽고 삭제하면서 이전 작업의 메시지가 잘못된 화면에 표시되었다.

### 기존 흐름

```text
관리자 등록 성공
→ 세션에 successMessage 저장
→ 대시보드로 이동
→ 대시보드에서 메시지를 읽지 않음
→ 메시지가 세션에 계속 남음
→ 다음 관리자 추가 화면에서 메시지 표시
```

## 검토한 대안

### 1. 관리자 추가 화면에서 메시지를 계속 처리

등록 후 대시보드로 이동하므로 성공 메시지가 표시되어야 할 화면과 맞지 않는다.

### 2. JavaScript `alert()` 사용

구현은 간단하지만 화면 스타일과 일관되지 않고 페이지 이동 과정에서 메시지 전달 책임이 명확하지 않다.

### 3. 대시보드에서 Flash Message 소비

등록 완료 후 실제로 이동하는 대시보드에서 메시지를 한 번 표시하고 즉시 세션에서 삭제할 수 있다.

## 결정 및 해결

관리자 등록 성공 메시지는 대시보드에서 소비하도록 변경했다.

`DashboardController`가 세션의 메시지를 request 속성으로 옮긴 뒤 삭제하고, 대시보드 JSP가 해당 메시지를 표시하도록 했다. 관리자 추가 JSP에 있던 성공 메시지 소비 코드는 제거했다.

### 개선된 흐름

```text
관리자 등록 성공
→ 세션에 successMessage 저장
→ 대시보드로 이동
→ DashboardController가 메시지를 request로 이동
→ 세션에서 메시지 삭제
→ 대시보드에서 한 번만 표시
```

## 결과

- 성공 메시지가 등록 결과를 확인하는 대시보드에 표시된다.
- 다음 관리자 추가 화면에 이전 메시지가 남지 않는다.
- 새로고침해도 동일한 성공 메시지가 다시 표시되지 않는다.

## 배운 점

세션에 저장하는 Flash Message는 단순히 저장하는 것뿐만 아니라 어느 화면에서 읽고 언제 삭제할지도 함께 설계해야 한다.
