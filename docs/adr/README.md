# 기술 의사결정 기록(ADR)

이 폴더에는 프로젝트를 개선하면서 내린 주요 기술적 결정과 그 이유를 기록합니다.
각 문서는 다음 순서로 작성하여, 코드를 보지 않아도 결정의 배경과 영향을 이해할 수 있도록 합니다.

1. 문제 상황과 변경 전 흐름
2. 결정 기준과 최종 결정
3. 변경 후 흐름과 검토한 대안
4. 기대 효과와 감수한 제약
5. 검증 결과와 관련 구현

검증 근거는 `코드 확인`, `빌드 확인`, `수동 검증`으로 구분합니다. 빌드 성공을 기능 동작의 증거로 사용하지 않고, 실제 요청 흐름은 별도의 수동 검증 결과로 기록합니다.

## 상태

- `제안`: 아직 적용 여부를 검토하고 있는 결정
- `승인`: 코드에 적용되어 현재 사용 중인 결정
- `대체됨`: 이후 다른 결정으로 변경된 기록
